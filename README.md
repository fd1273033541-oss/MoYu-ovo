# 耍起 V1.0

这是属于牛马的摸鱼利器。Windows 本地摄像头提醒工具：检测画面中的人员活动，登记机主面容后对匹配机主的目标排除提醒。

> 这是辅助提醒工具，不会判断他人的真实视线或意图，不是安防系统。请在取得必要同意的场所使用摄像头，不用于隐蔽监控。

## 安装版

[下载 Windows x64 安装包](https://github.com/fd1273033541-oss/MoYu-ovo/raw/refs/heads/main/dist/Shuaiqi-V1.0-Setup-x64.exe)

- 适用 Windows 10/11 x64；需要可用摄像头及 Edge/Chrome。
- 内置 Node 运行环境与识别模型，无须另外安装 Node 或下载模型。
- 桌面与托盘名称为“耍起 V1.0”，图标使用仓库内的 `奶龙.png`。
- 更新前退出旧版托盘程序，安装后从“耍起 V1.0”快捷方式启动。
- 安装包未签名；只运行你信任来源的文件。校验值见 [SHA256SUMS.txt](dist/SHA256SUMS.txt)。

## 使用顺序

1. 点击“录入机主特征”，允许摄像头访问。
2. 本人单独面对镜头，采集三次样本。
3. 点击“确认保存”。录入阶段只预览、采集，不运行监控或自动提醒。
4. 点击“开始监控”。匹配机主时静默，其他人员或身份不明目标可能触发提醒。
5. 可用“测试通知”检查本机通知，或在启动监控前开启短提示音。

取消录入保留原有机主特征。特征保存在当前浏览器、当前网址的 localStorage 中；可用“删除机主”清除。卸载程序不等于清除浏览器中的特征。

## 隐私与已知限制

- 图像处理在浏览器本地运行；本版本不上传摄像头画面，不保存照片。仓库中的模型是通用模型，不含机主登记数据。
- 服务仅监听 `127.0.0.1`。当前通知接口尚无鉴权、请求体大小限制或服务端限流，不应将端口转发或暴露到公网。
- 面容特征并非加密保险库；同源恶意脚本、恶意扩展或本机恶意软件可能访问数据。
- Windows 通知在开发机器上曾返回 `0x80070005` 拒绝访问，**本版未修复**。网页提示、接口提交成功均不等于通知中心实际显示成功。
- 不支持活体鉴别；照片、遮挡、光照、角度会导致误识别。机主背对镜头时可能被判为身份不明并提醒。
- 后台标签页可能被浏览器降速，不能保证最小化后的实时性；尚未进行跨电脑兼容性实测。

## 从源码运行

准备 Windows 和 Node.js 24 x64，在仓库目录运行：

```powershell
npm ci
npm test
npm start
```

开发版地址：`http://127.0.0.1:8787/`；安装版：`http://127.0.0.1:18787/`。两者的浏览器特征存储独立。模型已随源码提供，首次安装 npm 依赖需要网络。
